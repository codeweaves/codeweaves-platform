## Context

What is true today that forces a decision? Facts and numbers, not opinions. Include the measurement if there is one. Say what breaks or blocks if we do nothing.

## The four questions

- **Blast radius:** if this is wrong, what breaks and who notices?
- **One-way or two-way door:** how expensive is it to undo?
- **Couples us to:** vendor, licence, data shape, region, protocol.
- **Cost of waiting:** what do we lose by deciding later?

## Decision

What we are doing. Present tense, plain words. Tables are fine. Include the rules that follow from it, because a decision nobody can apply is not a decision.

## Options rejected

One block per option.

### <Option name>

**Good:** what was genuinely attractive about it. If you cannot write this honestly, it was not a real option.

**Rejected because:** the specific reason, tied to the context above.

**Revisit if:** the condition that would change this answer. Leave it out if there is none.

## Consequences

What gets better, what gets worse, what new work this creates, and what we now have to remember. Include the bad ones. An ADR with no downsides is marketing.
